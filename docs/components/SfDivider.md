# SfDivider

A hairline separator with an optional centered label.

[Live demo](https://softform-34r5.netlify.app/docs.html?component=SfDivider) · [Storybook](https://softform-34r5.netlify.app/storybook/?path=/story/components-sfdivider--default)

```vue
<sf-divider>or continue with</sf-divider>
```

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `as` | String | `'div'` |

## Events

None.

Native `class`, `style`, ARIA, and other undeclared attributes pass through to the root element.

Use `as` when a different semantic element fits the content.
