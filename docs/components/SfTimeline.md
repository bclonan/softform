# SfTimeline

An ordered activity list with connectors, descriptions, and times.

```vue
<sf-timeline :items="activityEvents" />
```

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `items` | Array | `none` |

## Events

None.

Native `class`, `style`, ARIA, and other undeclared attributes pass through to the root element.
