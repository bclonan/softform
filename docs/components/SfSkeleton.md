# SfSkeleton

A loading placeholder, with reduced-motion support and a status label.

[Live demo](https://softform-34r5.netlify.app/docs.html?component=SfSkeleton) · [Storybook](https://softform-34r5.netlify.app/storybook/?path=/story/components-sfskeleton--default)

```vue
<sf-skeleton kind="card" />
```

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `kind` | String | `'card'` |

## Events

None.

Native `class`, `style`, ARIA, and other undeclared attributes pass through to the root element.
