# SfMediaPlayer

A working native audio element with custom controls. The demo includes an original 12-second synthesized WAV.

```vue
<sf-media-player title="Ceramic" :src="audioUrl"
  subtitle="An original synthesized loop" />
```

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `src` | String | `none` |
| `title` | String | `'Ceramic'` |
| `subtitle` | String | `'An original synthesized loop'` |

## Events

None.

Native `class`, `style`, ARIA, and other undeclared attributes pass through to the root element.
